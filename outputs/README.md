# Dataset Partitions & Audit Artifacts

This directory contains the frozen manifests, identity-disjoint splits, evaluation pairs, and experimental protocol generated by Milestone 1 ([`notebooks/muzzle_dataset_audit.ipynb`](file:///e:/Internship/notebooks/muzzle_dataset_audit.ipynb)).

## File Index

| File | Description | Records / Details |
| :--- | :--- | :--- |
| **`manifest.csv`** | Full image manifest | 4,923 images across 268 cows with resolution, quality flags, camera source |
| **`splits.json`** | Cow identity splits & image roles | 160 train cows (2,922 imgs), 54 dev cows (1,012 imgs), 54 test cows (989 imgs) |
| **`splits.sha256`** | Cryptographic split integrity hash | `9f3559722045e421ba15450971ab9619a08449b5a9676a54946a33e2b75b11ba` |
| **`pairs_dev.csv`** | Development evaluation pairs | 1,878 genuine pairs / 6,260 impostor pairs (used for threshold tuning) |
| **`pairs_test.csv`** | Test evaluation pairs | 1,785 genuine pairs / 5,950 impostor pairs = 7,735 total frozen test pairs |
| **`protocol.md`** | Evaluation protocol definition | Rules for enrolment, query selection, guard frames, distortion testing |
| **`archive/muzzle_audit_outputs.zip`** | Standalone compressed bundle | Preserved archive of all milestone 1 artifacts |
